Repository deletion does not retire a service, database, disk, secret, account,
published website or bill. This cleanup makes no resource changes and claims no
savings. Verify consumers, retained data, recovery and actual charges before
retiring a resource. Preserve shared accounts and unrelated projects. The
[dated account ledger](DESKTOP_ACCOUNT_CLEANUP.md) is historical evidence, not a
live inventory. Use pinned historical source for legacy operational tools.
