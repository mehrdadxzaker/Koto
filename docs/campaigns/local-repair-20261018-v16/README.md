# V16: real canary success, failed full qualification

The authorized canary performed an actual Codex edit and completed the unchanged
independent assertions in **16.475 seconds using five local model requests**.
The remaining frozen battery then ran once. **Six of sixteen cases met the full
acceptance criteria**, so qualification failed. Automatic coding remains disabled
and ordinary coding readiness remains unknown.

## Correction and freeze

The TDD correction validates completed function arguments on the actual plain
local Codex 0.160 Responses route, without changing its provider request body,
catalog or four native tool schemas. Malformed replay receives a controlled
denial before provider dispatch. A malformed dispatched response remains unknown;
Koto never invents closing JSON, executes a tool or manufactures task success.
See [DIAGNOSIS.md](DIAGNOSIS.md) for the red/green and actual-profile controls.

managed-llama.v1 settings and native Codex 0.160.0 remain pinned. Revised

behavior check and prompt completion. Goals are disabled only in the isolated
run. Each episode permits eight forwarded model requests, 90 seconds and 512
output tokens per generation, zero retries and one native episode at a time.

## What this resolves, and what remains

The canary proves executable tool routing, an actual file edit, independent
assertion completion and normal Codex completion under the requested limits.
It used one behavior check and one redundant post-check reread. The matched V15
canary used seven requests and 35.596 seconds. The four development cases used
24 requests here versus 28 in V15, while the counter still exhausted its cap.
These are observed combined-treatment results; they do not isolate guidance,
router, engine caching or host-load effects. The held-out tasks differ between
campaigns and cannot establish an aggregate causal quality improvement.

The decimal case retained 575 bytes of incomplete argument deltas, ending in a
long literal run of zeros. The route withheld argument/item completion and
`response.completed`; Codex executed no corresponding command and reported a
disconnected stream. The file stayed unchanged. No malformed completed call or
local replay HTTP 500 reached this cohort. There is no completed usage record
for that request and no raw runtime-to-router capture, so its exact generated
token count and generator-versus-runtime-emitter attribution remain unproven.
The pinned generation cap remains 512; 448 is the largest **observed completed**
usage count. The gateway retains this attempt as unknown.

This corrects the unsafe completion/replay behavior, but does not make the
model/template/guidance combination reliably obey the eight-request workflow.
Repeated baseline probes, redefined functions, extra checks/rereads and explicit
contract mistakes remain. Eleven checker-zero implementations do not convert
the failed qualification into a pass. No receipt was installed and no automatic
coding was enabled. Another changed treatment requires fresh authorization.

## Retention and limits

[outcome/case-ledger.json](outcome/case-ledger.json) includes inspected synthetic
implementations, executed commands, separate checker/mechanical/accepted results,
per-generation observed usage and hashes of the immutable private originals.
[outcome/trial-summary.json](outcome/trial-summary.json) records totals and

owner-only durable archive. Public evidence does not contain every raw input
needed for independent public reproduction.

The earlier failed campaigns remain unchanged, including all 600 indexed V15
archive files. Both stages restored their isolated settings and closed owned
listeners/processes. Hard local-only enforcement, zero retries/failovers and zero
gateway answer-cache hits are preserved; engine prompt-cache reuse is separately
observed. The primary dirty checkout is unchanged. The live Codex file changed
during preparation, before the frozen model run; this work never wrote it, kept
the newer file, and verified its fingerprint remained stable through the run.
Only fingerprints were saved. No model download, commercial evaluation, history
learning expansion, automatic admission or merge occurred.
