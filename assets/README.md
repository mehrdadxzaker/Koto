# Koto assets

The logo and icon identify Koto in documentation and future delivery surfaces.
They do not establish an implemented IDE extension or UI.

`collaboration-flow.svg` explains the concurrent worktree and reviewed-integration
workflow. It is a documentation diagram with accessible labels, not a product
screenshot. The SVG keeps its technical labels left-to-right in both READMEs.

`badge-github.svg` links to the repository's star page without displaying a
count; `badge-license.svg` states the repository's Apache-2.0 license. Both are
local assets. The CI badge in the READMEs uses the actual GitHub workflow status.
